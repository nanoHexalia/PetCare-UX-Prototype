# Importar a Figma

1. Crear un archivo Figma llamado `PetCare — Actividad 2 UX/UI`.
2. Crear páginas: `00 Cover`, `01 UIKit`, `02 Wireframes`, `03 UI Propietario`, `04 UI Proveedor`, `05 Prototype`, `06 User Flow`, `07 Usability V1-V2`.
3. Arrastrar `PetCare_UI_Kit.svg` a la página `01 UIKit`.
4. Usar `design-tokens.json` como fuente de verdad de color, tipografía, espaciado y radios.
5. Crear componentes Figma a partir de botones, inputs, badges, cards y navegación del SVG/HTML.
6. Conectar el prototipo siguiendo el orden documentado en `docs/TRACEABILITY.md` y el flujo principal de la Actividad 1.

El archivo `.fig` debe crearse y guardarse desde Figma; el repositorio conserva formatos abiertos y reproducibles.
