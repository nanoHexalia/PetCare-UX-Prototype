# Checklist previo a publicar

- [ ] Revisión visual desktop 1440 px.
- [ ] Revisión responsive 768 px y 360 px.
- [ ] Navegación completa por teclado.
- [ ] Contraste y foco visible.
- [ ] Estados no dependen solo del color.
- [ ] No hay datos personales reales.
- [ ] Todos los enlaces del prototipo funcionan.
- [ ] Prueba de usabilidad real ejecutada y documentada.
- [ ] Cambios V2 trazados a hallazgos.
- [ ] Capturas de Figma y del HTML/CSS coinciden visualmente.
- [ ] PDF académico actualizado con evidencia V1 → prueba → V2.
- [ ] GitHub Pages se habilita solo después del QA final.
