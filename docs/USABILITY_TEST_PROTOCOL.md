# Protocolo de prueba de usabilidad — Actividad 2

## Participantes

Usar personas que correspondan a los perfiles objetivo. Mínimo recomendado para conservar continuidad con la Actividad 1: 4 propietarios y 2 proveedores. No usar datos sensibles.

## Tareas — propietario

1. Iniciar sesión como propietario.
2. Encontrar un servicio de veterinaria para una fecha y zona concretas.
3. Evaluar confianza, precio y condiciones de un proveedor.
4. Seleccionar mascota y horario, revisar y enviar una solicitud.
5. Identificar claramente si la solicitud está Solicitada o Confirmada.

## Tareas — proveedor

1. Abrir solicitudes pendientes.
2. Revisar una solicitud y los datos operativos mínimos de la mascota.
3. Confirmar o rechazar la solicitud.
4. Consultar agenda y detectar un horario bloqueado.
5. Identificar dónde editar el catálogo de servicios.

## Métricas

- Éxito de tarea: Sí / Parcial / No.
- Tiempo aproximado.
- Errores o retrocesos.
- Dificultad percibida 1–5.
- Comentario textual breve.
- Severidad del hallazgo: Alta / Media / Baja.
- Decisión de diseño.

## Regla de iteración

Cada cambio V2 debe relacionarse con un hallazgo real. Conservar captura V1, observación, decisión y captura V2.
