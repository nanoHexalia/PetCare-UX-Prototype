# Simulacion de resultados (ensayo del pipeline)

> ESTA CARPETA ES SIMULACION. Los datos de RESULTADOS_SIMULADOS.csv, ANALISIS_SIMULADO.md e ITERACION_V2_SIMULADA.md fueron generados para ensayar el analisis y mostrar el formato de la seccion 11 del informe. NO constituyen evidencia de pruebas con usuarios reales y no deben presentarse como tal en la entrega (misma regla del escenario sintetico de la Actividad 1).

Contenido:
- RESULTADOS_SIMULADOS.csv: 6 participantes simulados x tareas, con exito, tiempos, friccion, citas y SUS.
- ANALISIS_SIMULADO.md: metricas globales y por tarea, fricciones agrupadas, verbatims y limites honestos de la simulacion.
- ITERACION_V2_SIMULADA.md: banco de decisiones candidatas de diseno con el formato V1 -> hallazgo -> decision -> V2.

Uso legitimo:
1. Ensayar las sesiones reales (el moderador puede leer el analisis para saber que observar).
2. Validar el pipeline de datos antes de invertir tiempo en sesiones reales.
3. Plantear decisiones candidatas que las pruebas reales confirmaran o refutaran.

Regla dura: en el informe final, la seccion 11 se escribe UNICAMENTE con datos reales de docs/usabilidad/RESULTADOS.csv. Si un hallazgo real coincide con uno simulado, se cita el real.
